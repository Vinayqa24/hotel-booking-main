# Intake docs (stakeholder inputs)

This folder contains reusable templates for collecting inputs that enable evidence-based analysis.

## SCRUM-26 — Screenshots + App description intake

Use these files for stakeholder input collection for [SCRUM-26](https://vinayqa24-1792155730342.atlassian.net/browse/SCRUM-26):

- `app-intake.md` – full intake template (links, flows, data, scope, known issues, run/build notes)
- `app-description-template.md` – concise (5-10 bullets) app description template
- `clarification-request-template.md` – copy/paste template for requesting missing inputs in Jira

## Recommended storage convention
- Primary: attach screenshots to the Jira story (SCRUM-26)
- Optional: mirror in repo at `docs/evidence/SCRUM-26/` (avoid binaries if not allowed by repo policy)

## Completeness rubric (quick check)
- Readability: labels/fields legible at 100% zoom
- Coverage: at least one key booking-related screen
