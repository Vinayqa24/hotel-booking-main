# SCRUM-25 — Submissions

Documents how to submit baseline inputs (SCRUM-25). Submit as either: (A) repo-based folders with images or (B) external storage links (if screenshots cannot be committed).

## Option A: Repo-based

[  ] /docs/intake/submissions/<YYYY-MM-DD_team-or-contributor>/
- [ ] screenshots/ (screen-01.png, screen-02.png,...)
- [ ] app-description.md (filled from template)
- [ ] constraints.md (filled from template)
- ] submission-metadata.md

## Option B: External storage

- Upload screenshots to an approved location
- Add links to that location in submission-metadata.md

## Non-negotiable

- At least one full-page screenshot showing primary journey + global nav (legible)
- app description (5-10 bullets)
- constraints (env URL, mocks/real, limitations)
- roles coverage statement (guest/admin or "admin not supported")
