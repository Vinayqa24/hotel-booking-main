# Contributing Guidance

This repository contains a small hotel booking demo app (Local Node server + SQLite).

Before submitting changes, please run the checks in `README.md` when possible.

---

## Stakeholder inputs (SCRUM-26)

SCRUM-26 is a meta-story that collects evidence (screenshots) and a brief app description so the team can produce an evidence-based feature inventory, gap analysis, and prioritized enhancements.

**To submit inputs:**

1. Open [SCRUM-26](https://vinayqa24-1792155730342.atlassian.net/browse/SCRUM-26)
 2. Attach readable screenshots (key fields legible at 100% zoom)
 3. Fill in the intake template: `docs/intake/app-intake.md`
 4. *Optional*: if you need to mirror evidence in the repo, do so under `docs/evidence/SCRUM-26/` and update the index: `docs/evidence/SCRUM-26/evidence-index.md`

## Security / privacy

- Never include secrets (tokens, passwords, API keys).
- Never include real customer PII in screenshots or docs.
